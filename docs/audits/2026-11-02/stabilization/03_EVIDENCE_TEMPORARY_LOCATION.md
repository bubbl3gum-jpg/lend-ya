## Guarded local workflow

No bypass implementation was recovered or invented. The existing `TEST_LOCATION` architecture was retained: development mode, explicit enablement, matching local `hustlen_test_*` URL and valid test run ID, an actual matching database ownership marker, explicit preview and test-location allowlists for both participants, one centre per booking, explicit bilateral acknowledgement, fresh and accurate browser readings, per-stage check-ins, QR and receipt checks. Production MRT coordinates and normal geofencing are unchanged. The interface labels this a simulated `TEST_LOCATION` and now explicitly states that proximity to the shared centre does not measure distance between devices.

The existing local launcher creates a new database before migration and seed, marks it, and allowlists only its Alice and Bob test accounts. A smoke run found that the `tsx` process wrapper could exit on Ctrl-C before the demo process cleaned up. `package.json` now starts the same script with `node --import tsx`, allowing its signal handler to finish the owned-database cleanup. The initial run left its own marked `hustlen_test_task3_demo` database; after checking its exact run marker and confirming the server had exited, it was manually dropped. A direct-node attempt without npm's executable PATH failed to find `tsx` during seed and removed its own database. The corrected `npm run demo:meetup:local` created and seeded a fresh database, started the server, and on Ctrl-C reported removal; a subsequent PostgreSQL check found no `hustlen_test_task3_*` databases. npm reported exit 1 for the interrupt even though cleanup completed. No non-owned database was touched.

For local use, follow `docs/product/DEMO_RUNBOOK.md` and run `npm run demo:meetup:local` with `MRT_TEST_DATABASE_URL` pointing at a **new** local `hustlen_test_*` database name. The launcher creates and removes that database; use its two synthetic allowlisted accounts in separate browser contexts. The shared test centre is a simulation, not MRT arrival or direct inter-device distance. Do not use the demo for real customer data.
