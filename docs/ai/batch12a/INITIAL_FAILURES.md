3. **Test-runner TypeScript failure**: initial production run compiled application code but failed type checking because direct `env.NODE_ENV` assignment was readonly in the framework type contract; no refusal test executed. Corrected to the existing Object.assign environment pattern only for the two development flags. The actual production rerun then proved production=true, flagConfigured=true, route404/linkAbsent/stateUnchanged=true. This was a new harness compile defect, not a production authorization failure.

The final browser test explicitly checks retained textarea focus, keyboard review and actual touch review at mobile width. Screenshots scroll to page top so fixed Admin navigation is captured accurately; no product layout workaround was added.

The rejected command did not execute. The safer change excludes the production flag, preserves its explicit production override and is verified by an actual production build/start refusal run. No permission or security check was bypassed.
