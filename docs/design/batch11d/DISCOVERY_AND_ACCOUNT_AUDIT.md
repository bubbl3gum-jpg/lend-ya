## Money and data authority

`prisma/schema.prisma` persists price/deposit as Decimal(12,2), with no currency column or exchange-rate field. Creation parses bounded currency numbers; booking pricing multiplies persisted Decimal daily price by billable days. Existing detail formatter and 11C homepage/core formatter explicitly use **USD**. 11D preserves that existing UI contract; it does not claim an independently approved launch currency or convert to TWD. A production currency decision remains needed. Raw decimal values, deposits, dates, category identifiers, conditions, user titles/descriptions/names/details, station catalogue names and report descriptions are untouched. Known category/detail **labels** are presentation mappings only; unknown keys/values remain raw and escaped.

## Account security boundary

The account API changes the authenticated actor’s display name only. Email is read-only; no avatar/phone/email-verification or password edit exists. `app/api/auth/forgot-password/route.ts` is a non-delivering stub. Existing own-session Admin overview and development-only passkey restrictions remain unchanged. See the separate proposal before any password change/recovery implementation. No staff, MFA, approvals, Support, station or evidence authority follows from locale selection.
