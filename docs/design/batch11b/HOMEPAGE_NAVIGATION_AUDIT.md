## Available navigation contract

Public destinations: Home `/`, Browse `/listings`, Categories `/#discovery`, MRT pickup stations `/listings#marketplace-filters`, Customer service `/customer-service`. Desktop home/proof uses the heritage rail; smaller screens replace it with Explore's native sheet. Other marketplace headers show the same destinations in a desktop toolbar or Explore sheet. No duplicated visible rail/toolbar on the home/proof surface.

Authenticated account destinations retain Dashboard, public own profile, Account Settings, Activity logs, My listings, My borrowings and Trust/verification. Messages uses the original chat gate. Admin Desktop uses the existing server-resolved ADMIN role; destination guards remain authoritative. Appearance & sound links to actual home preferences. Anonymous users get Log in/Sign up, not fabricated private controls.

Logout uses the unchanged `LogoutButton`/real session invalidation and full document navigation. It remains available in normal header chrome and within the account sheet; the outside control is hidden/inert while a sheet is open so a modal never forces users to reach an obstructed control. This is UI placement, not new session logic.

## Explicitly deferred

No standalone map service, live station conditions, ratings/favorites/notification counts, language selector, password/recovery/MFA change, Admin redesign or operational setting editor. Non-shell portions of legacy operational/detail/messages/Support pages retain their existing presentation; this is not a full-route theme makeover. R1's first legacy preference migration mismatch and physical-device/accessibility/listening acceptance remain tracked. The intermittent login navigation deadline observed in R1 is not considered fixed by this integration.
